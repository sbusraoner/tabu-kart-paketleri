# Tabu kart paketleri

Tabu uygulamasının internetten indirdiği kart desteleri (Türkçe ve İngilizce; kolay, orta, zor).

- `packs/manifest.json`: hangi destenin hangi sürümde olduğunu listeler
- `packs/<dil>/<seviye>.json`: desteler

Bu dosyalar uygulama projesindeki `tools/build_cards.py` ile üretilir; elle düzenlenmez.
